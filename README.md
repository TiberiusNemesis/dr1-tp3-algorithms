# DR1 TP3 Recursive Algorithms

The project implements twelve recursive algorithm exercises using Python 3
and the standard library.

Run each exercise separately from this directory. For example:

```bash
python3 exercise_01.py
python3 exercise_12.py
```

Each file from `exercise_01.py` through `exercise_12.py` contains the code
and demonstration for its exercise. The files use only the Python standard
library and can be executed independently.
